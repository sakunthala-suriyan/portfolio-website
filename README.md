## 🌐 Deploying to GitHub Pages or Netlify (Free Hosting)

To share this live portfolio with recruiters on LinkedIn:

### Option A: GitHub Pages (Recommended)
1. Initialize a git repository or upload the files to a new GitHub repository (e.g. `sakunthala-portfolio`).
2. Copy the 4 dashboard screenshots into the `assets/images/` folder:
   - `ecommerce-dashboard.png`
   - `hr-dashboard.png`
   - `ev-dashboard.png`
   - `phonepe-dashboard.png`
3. Go to **Settings > Pages** in your GitHub repository.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`!

### Option B: Netlify
1. Go to [netlify.com](https://www.netlify.com).
2. Drag and drop the `portfolio-website` folder directly into the Netlify dashboard.
3. Your site is instantly deployed with a custom URL.
